# しゃぼん玉せっけん 在庫管理

価格一覧 Excel（`202505しゃぼん玉せっけん　価格一覧.xlsx`）をもとにした、PC向けの在庫管理アプリです。

---

## 初回セットアップ（デプロイ）

1. **`インストール.bat`** をダブルクリック（1回だけ）
2. 完了後、**`起動.bat`** またはデスクトップの **「しゃぼん玉在庫管理」** で起動

### 必要な環境

- Windows 10 / 11
- [Python 3.10 以降](https://www.python.org/downloads/)（インストール時に **Add python.exe to PATH** にチェック）
- [Node.js LTS](https://nodejs.org/)（画面のビルド用・`インストール.bat` で自動ビルド）

---

## 日常の使い方

| 操作 | ファイル |
|------|----------|
| 起動 | `起動.bat` またはデスクトップショートカット |
| 停止 | 起動窓を閉じる / `停止.bat` |
| データバックアップ | `バックアップ.bat` → `backups\` に保存 |

ブラウザ: **http://127.0.0.1:5050**

---

## 画面の説明

| タブ | 内容 |
|------|------|
| **在庫一覧** | 全品目の在庫・入出庫 |
| **動きのある品目** | 入出庫記録がある品目だけ |
| **増減履歴** | 品目を選んで、その品目の増減（＋／−）履歴を表示 |
| **品目編集** | 商品の追加・編集・削除 |
| **入出庫履歴** | すべての品目の入出庫ログ（増減列付き） |

## 別店舗へ URL で共有する（固定URL・PC不要）

**Render は使いません。**  
Supabase（データ）+ GitHub Pages（画面）で固定URLにします。見た目・操作はそのままです。

→ **`Supabase公開の手順.md`** を開いてください

- 例: `https://pv-dn.github.io/shabon-inventory/`
- PCの電源は切ってOK
- データはしゃぼん玉専用の Supabase に保存（他アプリと混在させない）

ローカルのみ: これまでどおり `起動.bat` → http://127.0.0.1:5050


---

## 別のPCへ配布する（ローカル版）

1. **`配布用ZIP作成.bat`** を実行 → デスクトップに ZIP ができる
2. ZIP を相手のPCにコピーして解凍
3. 相手のPCで **`インストール.bat`** → **`起動.bat`**

※ `data\` フォルダごとコピーすれば、在庫データも引き継げます。

---

## 設定（config.json）

```json
{
  "host": "127.0.0.1",
  "port": 5050,
  "open_browser": true
}
```

| 項目 | 説明 |
|------|------|
| `host` | `127.0.0.1`＝このPCのみ。店舗内の他PCから使う場合は `0.0.0.0` |
| `port` | ポート番号（既定 5050） |
| `open_browser` | 起動時にブラウザを自動で開く |

`host` を変更したら `起動.bat` を再起動してください。

## トラブルシュート

| 症状 | 対処 |
|------|------|
| 起動しない | `インストール.bat` を再実行 |
| 画面が「ビルドされていません」 | Node.js を入れて `cd frontend` → `npm install` → `npm run build` |
| 編集ボタンが効かない | ブラウザで **Ctrl+F5**、または `停止.bat` → `起動.bat` |
| ポート使用中 | `停止.bat` を実行してから再起動 |
| Excel取込 | デスクトップに価格一覧 xlsx を置き、アプリ内「Excelから再取込」 |

---

## 補足

- 本番サーバーは **Waitress** を使用（開発用 Flask サーバーではありません）
- 品目削除時、入出庫履歴も削除されます
- Excel再取込時、手入力した価格は Excel が空欄なら保持されます
